Conclusiones

    Corridas

    Tocá una fila para ver el detalle. Objetivo: turno p95 ≤ 2,5 s y todas las llamadas ok.

    Cómo leer

    • Turno: desde que el operador (robot) termina de hablar hasta que el agente empieza a responder. Incluye la pausa que espera el agente para saber que terminó (~0,5 s), el reconocimiento de voz, el clasificador, el núcleo y la voz.
    • Saludo: desde que el robot entra a la sala hasta que el agente empieza a hablar. 0 s = el agente ya estaba hablando cuando el robot terminó de conectarse.
    • Audio conectado: desde que el robot entra hasta que recibe el audio del agente. El agente no habla hasta que alguien lo escucha.
    • CPU: uso de la máquina del agente cada 2 s. Por encima de 70 % el worker deja de aceptar llamadas nuevas.
    • Ramp: pausa entre una llamada y la siguiente. 0 = todas en el mismo segundo.
